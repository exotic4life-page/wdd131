Site Name & Logo

Site Name: DevCraft Academy

Description: I chose "DevCraft Academy" because it conveys a practical, craft-oriented approach to modern web development and software engineering education.

Optional Domain: devcraftacademy.org

Site Purpose

DevCraft Academy serves as an interactive hub for aspiring web developers. The site provides beginner-friendly programming tutorials, curated resource roadmaps, project showcases, and a course enrollment form to help students get hands-on experience building modern web applications.

Target Audience Scenarios

  • Scenario 1: "Where can I find beginner-friendly HTML, CSS, and JavaScript learning roadmaps?"
  • Scenario 2: "How do I sign up for upcoming web development workshops and contact the instructors?"

Typography

Heading Font: Montserrat (Sans-Serif) – Used for primary page titles, section headings, and branding elements.

Body Font: Open Sans (Sans-Serif) – Used for paragraph text, list items, and form descriptions for clean legibility.
